# Keybindings

`Mod` is Super by default. The source of truth is
[binds.kdl](../modules/niri/.config/niri/noctalia/binds.kdl).

| Keys | Action |
| :--- | :--- |
| `Super + Return` | Kitty |
| `Super + Space` | Launcher |
| `Super + E` | Nautilus |
| `Super + D` | Control center |
| `Super + I` | Noctalia settings |
| `Super + P` | Session / power menu |
| `Super + L` | Lock |
| `Super + V` | Clipboard |
| `Super + W` / `Super + Shift + W` | Next / random wallpaper |
| `Super + Shift + C` | Toggle idle inhibitor |
| `Super + Tab` | Overview |
| `Alt + Tab` / `Alt + Shift + Tab` | Recent windows on this output |
| `Super + arrows` | Focus column / window |
| `Super + Shift + arrows` | Move column / window |
| `Super + 1…9` | Focus workspace |
| `Super + Shift + 1…9` | Move column to workspace |
| `Super + F` / `Super + M` | Fullscreen / maximize column |
| `Super + T` | Toggle floating |
| `Super + Y` | Toggle tabbed column |
| `Super + Q` | Close window |
| `Print` / `Ctrl + Print` | Region / fullscreen screenshot |
| `Super + Shift + /` | Show full hotkey overlay |
| `Super + Shift + Q` | Quit niri |

Volume, media, microphone, and brightness keys call Noctalia's IPC. Those
shortcuts need Noctalia running; window movement and workspace shortcuts are
native niri actions.
