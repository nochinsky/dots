# dots

A minimal Arch Linux desktop built around **niri + Noctalia**.
Rounded windows, a quiet bar, and wallpaper-derived monochrome colors.

![Niri and Noctalia desktop with a scenery wallpaper and monochrome terminal](assets/desktop.webp)

## Configs

- [niri](modules/niri/.config/niri/) — windows, workspaces, and keybindings.
- [Noctalia](modules/noctalia/.config/noctalia/) — bar, launcher, panels, and locking.
- [Other modules](modules/) — Kitty, GTK, fonts, shell, and wallpaper.

Each module mirrors paths in your home directory. Take individual files or the
full setup; adapt the display settings and local paths to your machine.
